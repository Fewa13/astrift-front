# Ancient Age 第二条主线

保留原有 335 个任务的 ID 和顺序，不重置玩家计数。新章只追加在圣域结尾之后。

1. 蚀影荒原（90 级）：部分魔化生命仍能恢复。调查营地、保护净化设备、救援村落，追踪到裂隙。
2. 净界圣域（120 级）：发现净化装置把正常生命也当作燃料。纠正光路、终止裁决，获得救人而非抹除生命的净化方法。
3. 沉星遗境（150 级）：圣域装置仍在向海底星核抽取能量。读取潮汐记录，修复沉没书库，切断两条回路，解除执核者的旧命令。

新章分三段：入口 150–157 级，书库 160–167 级，封印区 170–177 级；最终 BOSS 180 级。
160、170、180 级之前穿插每轮 20 只怪的巡逻和回报任务，达到目标等级自动进入下一段，不要求重复刷完当前轮。
任务奖励遵循小比例补充，主要经验仍来自战斗。所有物件交互使用已有动作系统，非当前任务的任务物件不额外常驻。

## 数值约束

- 三种普通怪的同级 HP、伤害分别与圣域守卫、镜光灵体、封印执卫完全一致。
- BOSS 的同级 HP、基础伤害、基础经验与无瑕裁决者一致；所有技能预警先于结算，三种攻击循环。
- 普通怪使用统一后期经验曲线；经验最终仍只乘一次 1.20，药水、贡献分配、金币算法不变。
- 固定 24 只普通怪 + 1 个 BOSS，沿用现有死亡/复活规则；静态场景分块合并，怪物按关节合并并缓存模板。
- 以上是公式一致性，不等于对所有装备和技能组合的绝对平衡保证；实战偏差需继续观察。

## AdminTest

首次加载资料时补齐当前所有已定义的 BOSS 变身卡至各 999 张，不需要重新登录或踢掉当前会话。
测试面板可修改玩家等级（1–10000，经验清零）、技能等级（1–200），并手动补齐变身卡。服务端验证登录账户名，普通账户不可调用。此处是手动设置范围，不是普通玩家自然升级上限。
